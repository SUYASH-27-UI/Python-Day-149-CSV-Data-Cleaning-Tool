# Python Day 149 – CSV Data Cleaning Tool

## Description
A Python application that cleans CSV files by removing duplicate records, extra spaces, and incomplete entries.

## Features
- Reads CSV files.
- Removes extra spaces.
- Detects duplicate records.
- Removes incomplete records.
- Generates a cleaned CSV file.
- Displays a cleaning report.

## Files
- `data_cleaner.py` – Main Python program.
- `students.csv` – Original sample data.
- `cleaned_students.csv` – Generated clean data.

## How to Run
```bash
python data_cleaner.py
```

## Concepts Used
- CSV Module
- Dictionaries
- Sets
- File Handling
- Data Cleaning
- Exception Handling
